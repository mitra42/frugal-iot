# Frugal-IoT Loadcell

Frugal IoT - Loadcell scales application

A load cell (HX711) scale with a local menu, driven by buttons, to see the weight, tare it,
calibrate it, and choose a language. The menu has three parts that are chosen separately (see `src/control/menu.h`):

- **What it holds**: a tree of `Menu`, `MenuLine` and `MenuNumber`, built in `loadcell.ino`
- **How it is driven**: `Control_Menu_Simple`, with up, down, accept and back keys
- **Where it is shown**: the displays added with `addDisplay()`. This example always uses
  `Menu_Display_Serial`, so it runs on a board with nothing but buttons attached, and adds
  - an LCD with `ACTUATOR_LCD_WANT`
  - the LCD of another node with `CONTROL_MENU_LCD_NODE="esp32-12bc34"` (same org and project)
  - the OLED, on a board that has one
  - the captive portal page, with four buttons, with `CONTROL_MENU_CAPTIVE_WANT`

```
Scale
├── Weight      shows the reading; accept publishes it on menu/weight
├── Tare        sends 0 to loadcell/output
└── Settings
    ├── Calibrate   number, starting from the current reading, sent to loadcell/output
    └── Language    English / Deutsch / Bahasa Indonesia
```

## Wiring

Each button goes between its pin and GND. Holding up or down repeats, and gets faster the
longer you hold it. The pins are set per board in `platformio.ini` (the `build_flags_pins_*`
groups), so change them there.

| | S2 Mini | C3 72x40 OLED | D1 Mini |
|--------|---------|---------|---------|
| Up     | 3       | 3       | D5 (14) |
| Down   | 5       | 4       | D6 (12) |
| Accept | 7       | 10      | D7 (13) |
| Back   | 9       | 7       | none, so each menu ends in a "Back" row |
| HX711 DOUT / SCK | 33 / 35, or 16 / 18 with an LCD or OLED | 0 / 1 | D2 (4) / D1 (5) |
| LCD or OLED (I2C) | SDA 33, SCL 35 | built in | |

**One button** - define `SENSOR_BUTTON_ONE_PIN` instead of the four, e.g. the board's boot button.
Click for the next row (while editing a number, the next one down), double click to accept, hold
to step, faster the longer it is held. Each menu ends in a "Back" row to go back.

**No load cell** - leave out `SENSOR_LOADCELL_DOUTPIN` and `_SCKPIN`, to try the menu on a board
with nothing attached. The weight then shows nothing.

## PlatformIO

1. Copy this folder (`examples/loadcell` in [frugal-iot](https://github.com/mitra42/frugal-iot)) to wherever you keep projects.
2. In VS Code, **PlatformIO Home > Open Project**, and choose that folder.
3. In the status bar, pick the environment for your board from the table below, and plug the board in.
4. **Upload** (→), then **Serial Monitor** (the plug icon) to watch it start.

Or from a terminal: `pio run -e s2_mini -t upload -t monitor`

## Arduino IDE

1. **Tools > Manage Libraries**, install **Frugal-IoT**, and choose **Install All** when it asks about dependencies.
2. **Tools > Board > Boards Manager**, and install the one for your chip: **esp32** by Espressif Systems, or **esp8266** by ESP8266 Community (first add `https://arduino.esp8266.com/stable/package_esp8266com_index.json` under **File > Preferences > Additional boards manager URLs**).
3. **File > Examples > Frugal-IoT > loadcell**, then **File > Save As** to keep your own copy.
4. ESP8266 only: **Sketch > Show Sketch Folder**, and rename `X_loadcell.ino.globals.h` to match your sketch, e.g. `loadcell.ino.globals.h`.
5. **Tools > Board**: the row for your hardware in the table below. **Tools > Port**: your board.
6. **Upload** (→), then **Tools > Serial Monitor** at 115200 baud to watch it start.

## Arduino IDE problems

* *Frugal-IoT.h: No such file or directory* - the library is not installed (step 1); opening the `.ino` from a download does not install it.
* *text section exceeds available space* - **Tools > Partition Scheme > Minimal SPIFFS** if offered. Otherwise rename `min_spiffs.csv` to `partitions.csv` in the sketch folder and choose **No OTA (2MB APP/2MB SPIFFS)**; OTA still works, as `partitions.csv` sets the real layout.
* *loramesher.hpp: No such file* (Heltec WiFi LoRa 32(V3)) - download [LoRaMesher as a zip](https://github.com/loramesher/LoRaMesher/archive/refs/heads/main.zip), **Sketch > Include Library > Add .ZIP Library**, then install **RadioLib** from the Library Manager.
* A board listed twice - you get the row with an empty last column unless you define that macro: on ESP32 put the line `-DS2_MINI_LCD` in a file `build_opt.h` beside `loadcell.ino` (compiler flags, not a `#define`).
* Board not in the table - the build stops and lists the ones that are. `examples/all/platformio.ini` has more boards: copy one into this `platformio.ini`, add this example's pins, and re-run `scripts/generate_platform_h.py`.
